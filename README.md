# 💰 SmartBudget

SmartBudget es una aplicación web orientada a la gestión y organización de las finanzas personales.

El proyecto fue desarrollado como parte de mi formación en Desarrollo Front-End, aplicando conceptos de estructura web, estilos, diseño responsive y organización de recursos mediante HTML, CSS y SASS.

## 🌐 Demo

Puedes visualizar la aplicación directamente en GitHub Pages:

👉 https://danisa23.github.io/SmartBudget/

## ✨ Características

- 💰 Interfaz enfocada en la gestión financiera.
- 📊 Presentación visual de información relacionada con las finanzas.
- 🧭 Navegación sencilla e intuitiva.
- 🎨 Diseño moderno y organizado.
- 📱 Adaptación a diferentes tamaños de pantalla.
- ⚡ Uso de SASS para la organización de estilos.
- 🖥️ Estructura desarrollada con HTML5.
- 🌐 Publicación mediante GitHub Pages.

## 🛠️ Tecnologías utilizadas

| Tecnología | Uso |
|------------|-----|
| HTML5 | Estructura de la aplicación |
| CSS3 | Estilos y presentación visual |
| SASS | Organización y preprocesamiento de estilos |
| JavaScript | Interactividad de la aplicación |
| Git | Control de versiones |
| GitHub | Gestión del repositorio |
| GitHub Pages | Publicación del proyecto |
| Visual Studio Code | Entorno de desarrollo |
